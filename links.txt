# 链接一行一个，格式：名字 | 网址 | 说明 | 图标 | 标签
#   网址写 - 表示只是说明卡、不跳转（比如「我的软件」那几张）。
#   说明、图标、标签都可以不写。图标不写时自动用网站自己的小图标，取不到就显示🔗。
#   标签有多个时用 / 隔开，如：安卓/自用。
# 以 # 开头的行是说明，不会显示到网页上。
# 加链接 = 加一行；删链接 = 删一行；删分类 = 把分类名连同它下面的行一起删掉。
